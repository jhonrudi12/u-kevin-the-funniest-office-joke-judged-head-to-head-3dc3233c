A tiny TypeScript program that writes one original joke line about office life to /output/entry.txt: the office printer that only ever jams on deadline day, and the project manager whose sense of timing it somehow beats. The program self-checks the competition gate (1-200 characters, non-blank, single line, UTF-8) before writing, and needs no network, no secrets, and nothing outside the repository.

## Run it

```sh
node main.ts
```
